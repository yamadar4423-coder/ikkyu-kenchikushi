このステップの進め方

部材を三角形に組んだ骨組をトラスといいます。梁やラーメンと違い、部材には引張か圧縮の軸方向力しか生じません。曲げを考えなくてよいぶん、つり合い式だけで機械的に解けるので、力学の中では得点源にしやすい単元です。

解き方は2つだけです。節点で力を足し合わせる節点法と、トラスを切ってモーメントをとる切断法。試験では「特定の1本の軸力」を問われることが多く、その場合は切断法のほうが圧倒的に速くなります。

A 前提知識の穴埋め

A-1 トラスとは

下の図は、上下の弦材を鉛直材と斜材でつないだ平行弦トラスです。本ステップの例題の多くはこの形で考えます。

  • トラスは部材を ＿ に組んだ骨組
  • 節点は ＿ で接合されていると仮定する
  • 荷重は ＿ にだけ作用すると仮定する
  • この2つの仮定から、部材に生じるのは ＿ だけで、曲げモーメントは ＿
  • したがって各部材は ＿ か ＿ のどちらかになる

A-2 符号と矢印の向き

  • 軸方向力は引張を ＿、圧縮を ＿ とする
  • 部材に働く力で見ると、引張は部材の両端を ＿ に引く
  • 節点に働く力で見ると、引張材は節点を ＿、圧縮材は節点を ＿
  • 未知の軸力は、はじめ全部 ＿ と仮定して式を立てる。結果が負なら ＿ と読み替える

A-3 斜材の分力

斜材の力は水平成分と鉛直成分に分けてつり合いを考えます。辺の比を覚えておけば三角関数は要りません。

斜材の角度水平成分 : 鉛直成分 : 斜材
45°1 : 1 : ＿
30°（水平から）＿ : 1 : ＿
  • 45°の斜材で鉛直成分が 4 kN なら、斜材の軸力は ＿ kN
  • 30°の斜材で鉛直成分が 5 kN なら、斜材は ＿ kN、水平成分は ＿ kN
  • √2 ≒ ＿、√3 ≒ ＿

A-4 節点法

  • 1つの節点で使えるつり合い式は ΣX = 0 と ΣY = 0 の ＿ 本
  • だから、未知の部材が ＿ の節点から解き始める
  • 支点のある節点は、反力を ＿ 求めてから使う
  • 節点ではモーメントのつり合いは使えない。すべての力が ＿ に集まっているから

A-5 切断法

  • 求めたい部材を含めて ＿ の部材を切る
  • 残り2本の部材の ＿ 回りでモーメントのつり合いをとると、求めたい1本だけが式に残る
  • 平行弦トラスの弦材の軸力の大きさ = その位置の ＿ ÷ ＿
  • 弦材が平行なとき、斜材の ＿ はそのパネルのせん断力に等しい
  • 下向き荷重の単純支持トラスでは、上弦材は ＿、下弦材は ＿。梁の上側が縮み下側が伸びるのと同じ
  • 片持ちトラスでは逆になり、上弦材が ＿、下弦材が ＿

A-6 ゼロ部材

計算しなくても軸力が 0 と分かる部材があります。試験で頻出なうえ、計算の手数も減らせます。

  • 部材が2本だけの節点に荷重がなく、2本が一直線でないとき、2本とも軸力は ＿
  • 部材が3本の節点に荷重がなく、そのうち2本が一直線のとき、残り1本の軸力は ＿
  • ゼロ部材は ＿ によって変わる。荷重が変われば判定し直す
  • ゼロ部材は不要な部材ではない。＿ や、荷重が変わったときに働く

B 解法手順の穴埋め

B-1 節点法の手順

  1. トラス全体のつり合いで ＿ を求める
  2. 未知の部材が ＿ の節点を選ぶ。多くは支点の節点
  3. 未知の軸力はすべて ＿ と仮定し、節点から離れる向きに矢印を描く
  4. 斜材は ＿ に分けて、ΣX = 0 と ΣY = 0 を立てる
  5. 求まった軸力を持って ＿ へ進む
  6. 結果が負の部材は ＿ と読み替える

B-2 切断法の手順

  1. 反力を求める。片持ちトラスなら先端側を使えば不要
  2. 求めたい部材を含め ＿ を横切る切断線を引く
  3. 力の数が ＿ 側を取り出す
  4. 弦材を求めるときは、残り2本の ＿ 回りで ΣM = 0
  5. 斜材を求めるときは、弦材が平行なので ＿ を使う
  6. 大きさは M ÷ h で出し、引張か圧縮かは ＿ で判断すると速い

B-3 ゼロ部材の探し方

  1. 荷重も支点も ＿ 節点に印をつける
  2. その節点に集まる部材の ＿ と、一直線に並ぶ組を確かめる
  3. 2本でL字なら2本とも 0。3本でうち2本が一直線なら ＿ が 0
  4. ゼロ部材を取り除くと、隣の節点で規則が新たに ＿ ことがある。繰り返し調べる

B-4 図を描く課題

下の平行弦トラスの全部材について、引張・圧縮・0 を紙に書き分けてください。数値まで出せればなお良いです。

答えの図を見る

上弦材は圧縮 8 kN、下弦材は引張 6 kN、端部の斜材は圧縮 6√2 kN、中間の斜材は引張 2√2 kN、荷重のかかる節点の鉛直材は引張 4 kN です。中央の鉛直材 L2U2 は、節点 U2 に荷重がなく上弦材が一直線なので 0 になります。

C 例題の数値穴埋め

例題1 三角トラス ― 節点法

スパン 4 m、高さ 2 m の三角トラス。A はピン、B はローラー。頂点 C に下向き 8 kN。各部材の軸力を求めよ。

① 左右対称なので VA = VB = ＿ kN
② 節点 A に集まる未知の部材は AC と AB の ＿ 本。ここから解ける
③ AC は 45°。ΣY = 0　4 + NAC × 1/√2 = 0　→　NAC = ＿ kN
④ ΣX = 0　NAB + NAC × 1/√2 = 0　→　NAB = ＿ kN
⑤ AC は ＿、AB は ＿
⑥ 対称なので CB も ＿ kN

反力 4 kN を斜材が鉛直成分で受け、その水平成分 4 kN を下弦材が引き戻す、という力の流れで覚えてください。

例題2 ゼロ部材を見つける

図の平行弦トラスで、節点 L2 だけに下向き 8 kN が作用している。軸力が 0 の部材をすべて挙げよ。

① 節点 L1 の部材は L0L1、L1L2、L1U1 の3本で、荷重は ＿
② L0L1 と L1L2 は ＿。よって L1U1 = ＿
③ 同じ理由で、節点 L3 から L3U3 = ＿
④ 節点 U2 は U1U2 と U2U3 が一直線で荷重なし。よって L2U2 = ＿
⑤ ゼロ部材は全部で ＿ 本
⑥ 荷重を L1、L2、L3 の3か所に載せると、L1U1 と L3U3 は ＿

⑥が大事です。ゼロ部材は形だけでなく荷重で決まります。B-4 のトラスと見比べて、L1U1 が 0 から 4 kN に変わることを確かめてください。

例題3 切断法 ― 弦材

スパン 8 m、高さ 2 m の平行弦トラス。節点 L1、L2、L3 にそれぞれ下向き 4 kN。上弦材 U1U2 と下弦材 L1L2 の軸力を求めよ。

① 反力　VL0 = VL4 = 12 / 2 = ＿ kN
② 第2パネルを縦に切る。切られる部材は U1U2、U1L2、L1L2 の ＿ 本
③ 上弦材 U1U2 を求めるには、残り2本の交点 ＿ 回りでつり合いをとる
　左側だけで L2 回りの曲げモーメント M = 6 × 4 − 4 × 2 = ＿ kN·m
④ 上弦材の軸力の大きさ = M / h = 16 / 2 = ＿ kN。梁の上側なので ＿
⑤ 下弦材 L1L2 は交点 ＿ 回り。M = 6 × 2 = ＿ kN·m
⑥ 大きさ 12 / 2 = ＿ kN。梁の下側なので ＿

節点法で端から順に解くと、ここまで来るのに節点を3つ通ります。切断法なら1本の式で済みます。1本だけ聞かれたら切断法が鉄則です。

例題4 切断法 ― 斜材と鉛直材

例題3と同じトラス・同じ荷重で、斜材 U1L2、鉛直材 L1U1、端部の斜材 L0U1 の軸力を求めよ。

① 例題3と同じ切断で、U1L2 以外の2本は平行なので交点が ＿。ΣY = 0 を使う
② 左側に働く鉛直力の合計、つまりせん断力 Q = 6 − 4 = ＿ kN
③ U1L2 は45°なので、鉛直成分 2 kN から N = ＿ kN
④ 左側を下へ引き戻す向きに働くので ＿
⑤ 鉛直材 L1U1 は節点 L1 の ΣY = 0。吊られた 4 kN を上へ引くので N = ＿ kN の ＿
⑥ 端部の斜材 L0U1 は節点 L0 の ΣY = 0。反力 6 kN を45°の斜材が受けるので N = ＿ kN の ＿
例題5 片持ちトラス

壁に A(0,0) と B(0,2) でピン接合された片持ちトラス。先端 E(4,0) に下向き 4 kN。上弦材 BD と下弦材 AC の軸力を求めよ。

① 片持ちなので反力を求めなくても、＿ 側を取り出せば解ける
② 第1パネルを切る。切られる部材は BD、BC、AC の3本
③ 上弦材 BD は交点 ＿ 回り。右側の 4 kN による M = 4 × ＿ = 8 kN·m
　大きさ 8 / 2 = ＿ kN。片持ちは上側が伸びるので ＿
④ 下弦材 AC は交点 ＿ 回り。M = 4 × 4 = ＿ kN·m
　大きさ 16 / 2 = ＿ kN の ＿
⑤ 上弦と下弦で大きさが違うのは、モーメントをとる点の ＿ が違うから

単純支持のトラスとは引張と圧縮が逆になります。片持ち梁の M図が上側に出たのと同じ理屈です。

例題6 30°の斜材

斜材の傾きが水平から30°の三角トラス。A はピン、B はローラー。頂点 C に下向き 10 kN。AC と AB の軸力を求めよ。

① 左右対称なので VA = VB = ＿ kN
② 30°の斜材は、鉛直成分 : 斜材 = 1 : ＿
③ 節点 A の ΣY = 0 で、AC の鉛直成分は 5 kN。よって AC の大きさは ＿ kN の ＿
④ AC の水平成分 = ＿ kN
⑤ ΣX = 0 から AB = ＿ kN の ＿。およそ 8.66 kN

斜材の角度が浅いほど、同じ荷重でも部材の軸力は大きくなります。45°なら 5√2 ≒ 7.07 kN だったものが、30°では 10 kN になります。

D 白紙演習（4問）

紙に節点の力の図を描いてから解答を開いてください。電卓は使いません。

D-1

スパン 8 m、高さ 4 m の三角トラス。頂点に下向き 10 kN。下弦材 AB と斜材 AC の軸力を求めよ。

解答
VA = VB = 5 kN
節点 A の ΣY = 0 → AC の鉛直成分 5 kN、45°なので AC = 5√2 kN の圧縮
ΣX = 0 → AB = 5 kN の引張
D-2

例題3と同じ平行弦トラスで、節点 L1、L2、L3 の荷重をそれぞれ 2 kN にした。U1U2、L1L2、U1L2 の軸力を求めよ。

解答
反力 3 kN ずつ
U1U2：L2 回り M = 3 × 4 − 2 × 2 = 8 → 8 / 2 = 4 kN の圧縮
L1L2：U1 回り M = 3 × 2 = 6 → 6 / 2 = 3 kN の引張
U1L2：せん断力 Q = 3 − 2 = 1 → √2 kN の引張

荷重が半分なら全部材の軸力も半分です。例題3・4と比べて確かめてください。

D-3

同じ平行弦トラスで、節点 L1 だけに下向き 4 kN。軸力が 0 になる部材を挙げよ。

解答
節点 L3：L2L3 と L3L4 が一直線、荷重なし → L3U3 = 0
節点 U2：U1U2 と U2U3 が一直線、荷重なし → L2U2 = 0
L1U1 は荷重を吊るので 0 ではない
D-4

例題5と同じ片持ちトラスで、先端 E の荷重を 6 kN にした。上弦材 BD と下弦材 AC の軸力を求めよ。

解答
BD：C 回り M = 6 × 2 = 12 → 12 / 2 = 6 kN の引張
AC：B 回り M = 6 × 4 = 24 → 24 / 2 = 12 kN の圧縮

F 本番形式（4択）

F-1 静定トラスの解析で用いる仮定と性質に関する次の記述のうち、誤っているものはどれか。

解説

節点がピンで荷重が節点にだけ載るので、部材に曲げは生じません。3 が誤りです。1 と 2 はトラスの前提そのもので、4 はその結果です。

F-2 図の平行弦トラス（スパン 8 m、高さ 2 m）の節点 L1、L2、L3 に、下向きの荷重 8 kN がそれぞれ作用している。上弦材 U1U2 の軸方向力として正しいものはどれか。

解説

単純支持で下向き荷重なので、上弦材は圧縮です。この時点で 1 と 3 は消えます。

反力 12 kN、L2 回り M = 12 × 4 − 8 × 2 = 32、32 / 2 = 16 kN。12 kN は下弦材 L1L2 の値で、切断位置の交点を取り違えたときに出る数値です。

F-3 図の平行弦トラスで、節点 L3 だけに下向きの荷重 4 kN が作用している。軸方向力が 0 となる部材の組合せとして正しいものはどれか。

解説

節点 L1 は荷重がなく、下弦材が一直線なので L1U1 = 0。節点 U2 は荷重がなく、上弦材が一直線なので L2U2 = 0。L3U3 は荷重を吊るので 0 ではありません。

弦材は荷重があれば必ず力を受けるので、4 は判定するまでもなく除外できます。
