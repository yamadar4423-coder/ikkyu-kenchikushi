    1日1時間の回し方

    1. 1日目　A と B を読んで穴埋め
    2. 2日目　C 例題の数値穴埋め
    3. 3日目　D 白紙演習と E 確認テスト。4/5 で合格
    4. 4日目　×だけ復習を回し、F 4択で本番形式に慣れる

    学科に電卓は持ち込めません。演習でも使わないでください。手計算のコツは Step 0 の A-7 にあります。

    進捗の保存と引き継ぎ

    ○×とテストの点数は、この端末のブラウザに保存されます。ブラウザのデータを消したり機種を変えたりすると失われます。月に一度、下のテキストをコピーしてメモアプリなどに貼っておいてください。

    スマホでの使い方

    1. Safari でこのページを開き、共有ボタンからホーム画面に追加。アプリのように開けて、保存データも消えにくくなります
    2. 一度開けばオフラインでも動きます。地下や電波の悪い場所でも使えます
    3. 右上の 🌓 で画面の明暗を切り替えられます
